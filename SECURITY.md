# Security Policy

## Supported versions

The latest pre-1.0 minor line and the default branch receive security fixes.
Older minor lines may become unsupported when a newer minor version is
available; this table will be updated when that policy changes.

| Version               | Supported |
| --------------------- | --------- |
| Unreleased (`master`) | Yes       |
| `0.1.x`               | Yes       |
| `< 0.1.0`             | No        |

## Reporting a vulnerability

Use GitHub's private vulnerability reporting form:

https://github.com/ngocdevv/dial-slider/security/advisories/new

Include the affected version or commit, platform, impact, reproduction steps,
and any suggested mitigation. Please allow the maintainer reasonable time to
investigate before disclosing the issue publicly.

Do not publish an exploit, proof of concept, secret, or sensitive user data in a
public GitHub issue. If private vulnerability reporting is not enabled, open a
minimal public issue asking the maintainer to enable GitHub Security Advisories,
without including vulnerability details.
