# @ngocdevv/dial-slider

Animated, photo-style dial slider for React Native and Expo with single- and
multi-preset modes, independent values, accessible actions, and UI-runtime
gesture motion.

```bash
bun add @ngocdevv/dial-slider
npx expo install expo-linear-gradient react-native-gesture-handler \
  react-native-reanimated react-native-svg react-native-worklets
```

```tsx
import {
  DialSlider,
  type DialPreset,
  type DialSliderProps,
} from '@ngocdevv/dial-slider';
```

See the [repository README](https://github.com/ngocdevv/dial-slider#readme) for
peer versions, native setup, single- and multi-preset examples, controlled and
uncontrolled behavior, the complete API reference, accessibility guidance, and
platform status.
